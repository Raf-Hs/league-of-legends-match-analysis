# DAX measures — HLE vs IG Power BI report

Copy-paste ready measures for the four report pages. Every measure below is
written against the tables in `data/powerbi/` as generated by
`src/export_powerbi.py`.

**Before you start**

1. Import the 16 CSVs from `data/powerbi/` (see `dashboard_guide.md`).
2. Set the data types listed in the guide. `date_key` must be **Whole number**
   and `date` must be **Date**, otherwise the date relationships break.
3. Create the relationships from the guide, then check that every measure below
   returns a value (a blank measure usually means a missing relationship or an
   unfiltered table).

**Table names used:** `DimDate`, `DimTeam`, `DimGame`, `DimMetric`,
`FactTeamGame`, `FactTeamForm`, `FactTeamKPI`, `FactMatchKPI`,
`FactTargetFeature`, `FactTeamEventStat`, `FactPrediction`, `FactScenario`,
`FactModelMetric`, `FactModelCoefficient`, `FactModelCalibration`,
`FactFeatureContribution`, and the optional manual table
`PostMatchValidationLog`.

## 1. Core performance (from `FactTeamGame`)

```dax
Games Played =
COUNTROWS ( FactTeamGame )
```

```dax
Wins =
SUM ( FactTeamGame[win] )
```

```dax
Losses =
[Games Played] - [Wins]
```

```dax
Win Rate =
DIVIDE ( [Wins], [Games Played], 0 )
```

```dax
Avg Gold Diff =
AVERAGE ( FactTeamGame[gold_diff] )
```

```dax
Avg GD10 =
AVERAGE ( FactTeamGame[gd10] )
```

```dax
Avg Kill Diff =
AVERAGE ( FactTeamGame[kill_diff] )
```

```dax
Avg Objective Score =
AVERAGE ( FactTeamGame[objective_score] )
```

```dax
Avg Duration (min) =
AVERAGE ( FactTeamGame[duration_min] )
```

```dax
First Blood Rate =
DIVIDE ( SUM ( FactTeamGame[first_blood] ), [Games Played], 0 )
```

```dax

    CALCULATE ( [Wins], FactTeamGame[side] = "blue" ),

```

## 11. Gotchas

1. **`DimTeam[team_code]` for IG is `iG`** (Oracle's Elixir spelling), not `IG`.
   Filter on `DimTeam[team]` instead of the code wherever possible.
2. **`FactTeamGame` contains 57 teams**, not 16 — it also holds the opponents
   outside the Worlds cohort. `DimTeam` covers all 57; filter
   `DimTeam[is_worlds_cohort] = 1` for the cohort view.
3. **`FactTeamForm` rows are pre-game snapshots.** A rolling value on the row
   of date *d* only reflects games before *d* — never join it to the same-day
   result without reading the definition.
4. **`FactMatchKPI` is a wide comparison table** (`hle_value`, `ig_value`,
   `diff_hle_minus_ig`) and has no team key, so it is used on its own page
   rather than through a relationship.
5. **`AVERAGE` ignores blanks.** `Avg GD10` is computed over the 1,188 rows
   that have a value, not over all 1,272 rows. Use `Games Played` with a
   `gd10` filter if you need the denominator.
6. **`FactPrediction[is_primary]`** is 1 only for `M3_core5`. The section 5
   measures filter on it, so they stay correct even if a new model is added.
7. **Never average a probability across models** — use `FactPrediction` row by
   row (one row per model) so each probability keeps its own context.
